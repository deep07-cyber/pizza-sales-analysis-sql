# Pizza Sales Analysis Using SQL

## 📌 Project Overview
This project focuses on analyzing pizza sales data using SQL to derive meaningful business insights.  
The objective is to strengthen SQL skills by solving real-world analytical questions related to revenue, product performance, and category contribution.

---

## 📂 Dataset Description
The dataset contains transactional sales data, including:
- Orders and order details
- Pizza types and categories
- Price and quantity information

### Tables Used:
- orders  
- order_details  
- pizzas  
- pizza_types  

---

## 🛠 Tools & Technologies
- SQL (MySQL / PostgreSQL)
- Relational Databases
- SQL Client / IDE (MySQL Workbench / pgAdmin)

---

## 🔍 Analysis & Business Questions
The project answers key business-driven questions such as:

--Retrieve the total number of orders placed.
--Calculate the total revenue generated from pizza sales.
--Identify the highest-priced pizza.
--Identify the most common pizza size ordered.
--List the top 5 most ordered pizza types along with their quantities.
--Join the necessary tables to find the total quantity of each pizza category ordered.
--Determine the distribution of orders by hour of the day.
--Join relevant tables to find the category-wise distribution of pizzas.
--Group the orders by date and calculate the average number of pizzas ordered per day.
--Determine the top 3 most ordered pizza types based on revenue.
--Calculate the percentage contribution of each pizza type to total revenue.
--Analyze the cumulative revenue generated over time.
--Determine the top 3 most ordered pizza types based on revenue for each pizza category.

---

## 🔧 SQL Techniques Applied
- Multi-table JOINs
- Aggregations and GROUP BY
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions for analytical calculations
- Revenue and percentage contribution analysis

---

## 📊 Key Insights
- A small number of pizza categories contribute a significant share of total revenue
- Top-performing pizzas drive overall sales performance
- Low-performing items indicate opportunities for menu or pricing optimization
- SQL analytical techniques enable efficient, business-focused decision-making

---

## 📈 Outcome
This project helped strengthen hands-on SQL skills by applying advanced querying techniques to real sales data and converting raw data into actionable business insights.
